## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with gradients, animations, and flexbox/grid
- **JavaScript (ES6+)**: Interactive features and DOM manipulation
- **Font Awesome 6.4.0**: Icon library (via CDN)
- **Google Fonts (Inter)**: Professional typography (via CDN)

## 📱 Responsive Breakpoints

- **Desktop**: > 768px (Full layout)
- **Tablet**: 768px - 481px (Adapted layout)
- **Mobile**: ≤ 480px (Stacked layout with hamburger menu)

## 🎯 Key Features

1. **Smooth Scrolling**: Navigation links smoothly scroll to sections
2. **Mobile Navigation**: Hamburger menu for mobile devices
3. **Intersection Observer**: Elements animate when scrolled into view
4. **Active Navigation Highlighting**: Current section highlighted in navigation
5. **Back to Top Button**: Appears after scrolling down
6. **Typing Effect**: Animated typing effect on hero subtitle
7. **Ripple Effects**: Button click animations
8. **Hover Effects**: Interactive hover states on all interactive elements

## 📊 Data Models & Storage

Currently, this is a static portfolio website with no backend or database. All content is hardcoded in HTML.
